# ZyberVPN Smoke Checklist

Перед каждым деплоем вручную проверить:

1. `/user <tg_id|@username>`
   Показываются трафик, онлайн-статус и список ключей.

2. `/resetuser <tg_id|@username> <reason>`
   Команда открывает экран подтверждения, без `reason` не выполняется.

3. `resetuser_cancel`
   После отмены данные пользователя не удаляются.

4. `resetuser_confirm`
   После подтверждения пользователь очищается как новый, в логах есть `ADMIN_RESETUSER_*`.

5. Покупка
   Оплата и выдача ключа проходят без регрессии.

6. Продление
   Renewal обновляет срок действия и не ломает доступ.

7. Ручная настройка
   Ссылка и сценарий подключения продолжают работать.

8. Техпроверка
   `python -m compileall app`
